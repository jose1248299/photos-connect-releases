# Photos Connect

Aplicación de FinisherData Photos para cargar automáticamente fotos y videos desde una carpeta de tu equipo.

## Descargar 0.1.0

- [Mac con chip Apple (Apple Silicon)](https://github.com/jose1248299/photos-connect-releases/releases/download/v0.1.0/Photos-Connect-distribution-0.1.0-mac-arm64.dmg)
- [Mac con procesador Intel](https://github.com/jose1248299/photos-connect-releases/releases/download/v0.1.0/Photos-Connect-distribution-0.1.0-mac-x64.dmg)
- [Windows de 64 bits — evaluación](https://github.com/jose1248299/photos-connect-releases/releases/download/v0.1.0/Photos-Connect-evaluation-0.1.0-win-x64.exe)

Los instaladores de Mac están firmados y notarizados por Apple. El instalador de Windows es una versión de evaluación y todavía no tiene firma digital de Windows.

## Primer uso

1. Instala Photos Connect e inicia sesión con tu cuenta de FinisherData Photos.
2. Selecciona una carpeta local, una cobertura y un álbum.
3. Agrega fotos o videos a la carpeta y consulta el avance de carga desde la aplicación.

El login es suficiente; no hay una confirmación adicional para autorizar la conexión. La aplicación conserva los permisos de tu cuenta y permite reanudar cargas después de una desconexión.

Se requiere una cuenta con acceso a un equipo activo en [FinisherData Photos](https://fotografo.finisherdata.com).

Este repositorio contiene los paquetes de instalación y sus sumas de verificación. El software es propiedad de FinisherData.
